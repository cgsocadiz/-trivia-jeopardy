How to Play Trivia Jeopardy
  1. The Board: Categories are shown across the columns. Point values increase by row according to clue difficulty.
  2. Active Team: The active team chooses an available tile. The host reads the clue aloud.
  3. Evaluating Answers: The host reveals the correct response. Award points for correct responses. If deduction is enabled, incorrect responses deduct that clue's point value.
  4. Daily Double: A secret tile allowing the active team to wager up to their current point total (or the board maximum).
  5. Double Jeopardy: A second round featuring new categories with doubled point values.
  6. Final Jeopardy: One decisive final question where all teams place confidential wagers before the clue is revealed!
