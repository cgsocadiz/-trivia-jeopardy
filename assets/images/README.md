# Images Directory

Place local image assets used by clues in this directory.

### Referencing Images in Questions:
In `questions.json` or through the Admin Clue Editor, specify relative image paths such as:
`assets/images/sample-mars.jpg` or `assets/images/mona-lisa.png`.

Remote HTTPS image URLs (e.g. Unsplash or Wikimedia Commons) can also be used directly.
