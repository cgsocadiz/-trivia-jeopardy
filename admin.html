Export Game Data

Download your modified trivia questions and configuration as questions.json.

How Static GitHub Pages Publishing Works:
GitHub Pages is a static host. Edits made in this admin panel reside in your browser memory until exported.
  1. Click Export questions.json.
  2. Replace the file at assets/data/questions.json in your local project.
  3. Commit and push the change to your GitHub repository (git commit -am "Update questions" && git push).
  4. GitHub Pages will automatically serve the updated trivia set to all visitors!
